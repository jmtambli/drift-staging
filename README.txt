DRIFT STAGING & DESIGN STUDIO — WEBSITE
=======================================
A 5-page static website. No build step or server needed.

PAGES
  index.html      Home
  services.html   Services
  portfolio.html  Portfolio (click any photo for a full-size lightbox)
  about.html      The Studio / About
  contact.html    Contact

TO PREVIEW
  Double-click index.html to open it in any web browser.

TO PUBLISH
  Upload the entire folder (keep the assets/ folder alongside the .html files)
  to any web host — Squarespace, Wix, Netlify, GitHub Pages, or your current
  provider. Point your domain (driftdesignandco.com) at it.

FOLDER LAYOUT
  *.html                 the five pages
  assets/css/style.css   all styling
  assets/img/portfolio/  optimized project photos (curated from your Staging folder)

NOTES
  - Photography is a curated selection (3-5 shots per project) from your
    Staging folder, resized and optimized for fast web loading.
  - MLS listing photos had their NORTHWEST MLS watermark trimmed.
  - Fonts (Cormorant Garamond + Jost) load from Google Fonts.
